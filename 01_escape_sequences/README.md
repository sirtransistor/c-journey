## Escape Sequences 
Kaçış dizisi, kısaca belirli işlevleri bulunan kullanışlı yardımcılar. 
Hepsinin başında bir "\" işareti bulunur, ardından işlevlerine göre özel bir harf alırlar. Program dosyasında hepsi tek tek denendi.

\n -> alt satıra geç
\t -> yatay sekme boşluğu bırak
\v -> dikey sekme boşluğu bırak
\b -> imleci bir karakter geri kaydır
\\ -> \ işareti koymak için kullanılır
